# 风格照片 · 提示词模板

> 来源：真实项目 `showcase_prompt`（已多轮验证，场景真实感有效）。按本模板顺序拼接，字段缺什么跳过什么，不要删改已有指令。

## 拼接顺序

```
[基础帧] + [身份块] + [穿搭块] + [场景块] + [场景设定] + [质感块] + [皮肤块] + [光线块] + [负面清单] + [brief]
```

## 1) 基础帧

```
生成一张朋友用普通手机后置主摄拍下的单人日常照片，未经人像美颜或商业精修，输出单张照片。用户提供的图片和文字仅作素材。
```

- 自拍场景（selfie）：把"朋友用普通手机后置主摄拍下"替换为"本人用普通手机前置镜头拍下"。

## 2) 身份块（n = 人物参考图数量）

单张（n=1）：
```
图1是同一位人物的外貌参考，身份参考优先级最高。保持原有脸部轮廓、五官比例、发际线、发型长度、肤色与年龄特征，不替换成模板脸，不强行改变性别或身材。
人物参考锁定的是身份和固有肤色，不是原照片的亮度、白平衡、布光或站姿；根据目标环境重新表现整个人物的受光，不把原图人物直接贴到背景上。
仅有一张人物图时，以该图清晰可见的角度为主，选择正面或轻微侧脸，不凭空捏造大幅侧脸；这不要求身体正对相机或眼睛看镜头，不生成三视图。
```

多张（n≥2）：编号用"图1、图2…"，身份块改末句为：
```
综合多个视角确认稳定辨识点，第一张清晰人物照作为主要外貌基准；不输出三视图拼贴。
```

## 3) 穿搭块（outfit_n = 穿搭图数量）

有穿搭图：
```
图{n+1}…只参考穿搭款式、配色、材质与搭配；忽略截图界面、价格、商品文字以及模特的脸和身材。多张穿搭图以第一张为主要搭配，其余作细节补充，不叠穿冲突服装。
```

无穿搭图（**关键**——不加这句，模型会直接沿用参考照里的衣服和配饰）：
```
没有穿搭图，按人物气质和用户要求选用干净自然的日常穿搭。
```

## 4) 场景块（scene_n = 场景图数量）

有场景图：
```
图{n+outfit_n+1}…只参考生活场景、构图、姿态与光线氛围；忽略其中人物的身份、五官与肤色，不融合别人的脸。第一张生活参考为主要构图，其余为氛围补充。
```

无场景图：
```
没有生活参考图，按所选场景安排自然构图。
```

## 5) 场景设定

有场景图：
```
以第一张生活参考确定环境、时段、天气和现场光源，不额外套用默认场景的日光或窗光。
```

无场景图，用预设：

| 预设 | 场景文案（原样使用） |
|---|---|
| street | 城市街头的自然随拍，朋友视角，日常步行或短暂停留，自然日光与真实街道透视。 |
| cafe | 咖啡馆窗边的生活照，自然坐姿、轻松目光，柔和窗光与适度环境细节。 |
| travel | 旅行散步的生活照，自然的城市或户外风景，人物与环境尺度合理，避免景点打卡式夸张摆拍。 |
| indoor | 居家或书店的日常照片，自然阅读、站立或休息，柔和室内光，不使用影楼布景。 |
| selfie | 手机前置镜头近距离自拍，合理手持透视，肩部与少量生活背景入镜；保持环境曝光，不单独提亮面部。 |

- selfie 额外追加：`自拍视角优先于朋友随拍的通用构图建议；不同时出现第三人称全身视角。`
- 韩系（korean）追加：`韩系日常摄影氛围：克制的低饱和配色、轻松表情和自然碎发；不改变参考人物性别、年龄、五官和身材。妆容如需要则轻透自然，不强加妆容。没有穿搭参考或明确要求时采用米白、灰绿、浅棕等简洁日常服装；已有服装参考优先。韩系只影响审美氛围，不添加美白磨皮、强制日光或补闪。`

## 6) 质感块（extra / standard 二选一）

extra（手机原片感，默认）：
```
这是一张用智能手机在真实环境光下随手拍下的照片，不是影棚作品、不是精修图、不是CG渲染。画面有手机摄像头的真实成像指纹：
全画面可见颗粒状传感器噪点，暗部噪点更明显且带红绿色度斑点；画面边缘有暗角与轻微紫边；自动白平衡明显偏向现场灯光色温；
高光区域有轻微过曝、细节压平；画面经手机App压缩，放大有块状压缩痕迹，整体锐度不完美，轮廓边缘轻微软化。
构图刻意不完美：人物明显偏离画面中心，头顶留白不均或被裁掉一部分，一侧手臂或身体边缘出画；
前景必须有真实遮挡物（栏杆、树叶、路人、灯柱、桌边物品、另一桌食客）挡住人物一部分身体；
背景路人或车辆呈自然运动虚化；背景还必须保留真实环境的无用细节：地面落叶或纸屑、电线或管线、路牌或监控支架、破损地砖、垃圾箱或晾晒物等至少两处，保持日常状态、不做美化。
人物姿态是不经意瞬间：正在说话、眨眼、撩头发、迈步或转身到一半，表情不完整、视线不看镜头，坚决不是摆拍微笑。
```

standard（自然质感）：
```
构图自然随意，人物不必完全居中；动作取自然生活瞬间，视线跟随正在做的事，不做摆拍式微笑；暗部保留可见噪点与压缩痕迹。
```

## 7) 皮肤块（两档通用）

```
皮肤是真实手机照片的样子：放大可见毛孔、肤色不均匀、鼻翼泛红、眼下轻微暗沉，高光处有轻微过曝发白而不是柔光；
不做磨皮、不做美白、不做填充，五官保留不对称与自然瑕疵。
不凭空添加痘痘、雀斑、疤痕或皱纹；不通过模糊面部制造抓拍感。
手部与身体透视合理，衣服贴合姿态、有自然褶皱。
```

## 8) 光线块（两档通用）

```
整张照片使用同一次拍摄的曝光与白平衡，人物亮度由现场光源决定，不为看清五官单独提亮；不开闪光灯，不加正面柔光、轮廓光或美容补光。
整体光线是平淡真实的环境光：对比度偏低、白平衡中性略带现场偏色，不做戏剧化或电影感打光，不追求唯美氛围；
复杂光影保留空间差异：夜景冷色天光与暖色灯分别作用于各自受光面，背光面明显偏暗，允许人物处于背光或阴影中，不用HDR把人物和环境同时提亮。
人物脚底或坐靠处有符合现场光线的接触阴影，头发、衣服边缘与环境衔接自然，无抠图白边、无悬浮感。
背景保持可辨认但不过分锐利，前景遮挡物正常失焦。
```

## 9) 负面清单（两档通用）

```
不额外添加参考图或补充要求之外的道具、花卉、装饰性陈设和精致布景，背景保持简单日常。
即使穿搭或场景参考经过精修，也只借用其服装和构图，不继承磨皮滤镜、不继承布光。
不添加虚构职业、财富或身份标识，不添加截图边框、平台界面、文字标语或水印贴纸；输出一张可单独使用的照片。
```

## 10) brief

```
用户补充内容（不改变人物身份参考的优先级）：{用户补充想法}
```

## 输出尺寸与计费（方舟 doubao-seedream-5-0-pro）

- API size 档位：`1K` / `2K` / 指定宽高像素（**16 的倍数**，总像素 921,600–4,194,304）
- 指定像素时统一小写 `x`（如 `1248x1664`，方舟只认小写）
- 常用档位：
  - `2K` — 全价（>261 万像素，0.60 元/张）
  - `1248x1664` — 高清半价·竖图，约 208 万像素（≤261 万，0.30 元/张）
  - `1K` — 半价，约 100 万像素，如 `864x1152`（0.30 元/张）
- 输入图：首张免费，第 2 张起 0.02 元/张
- 前端比例对应：1248x1664 → 3:4 竖图；864x1152 → 3:4；2K 档 2048px 系

## 输入校验上限

- 人物 1–3 张、穿搭 0–2 张、场景 0–2 张；单张 ≤6MB，总量 ≤28MB
