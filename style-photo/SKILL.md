# 风格照片生成

## Overview

把用户提供的人物参考照（+可选穿搭图、场景图）合成为一张"像朋友用手机随手拍"的真实感单人照片。全部经验来自真实项目的多轮迭代：场景可以做到真实，但**人物长相与造型气质由参考照决定，模型只会往"更好看、更精致"方向画，不会往"更素"走**。

## 工作流（按序执行）

### Step 1 · 收集输入与参数

| 输入 | 数量 | 作用 | 优先级 |
|---|---|---|---|
| 人物参考照 | 1–3 张 | 锁定身份：脸型、五官、发际线、肤色、年龄、发型 | **最高，必须** |
| 穿搭参考图 | 0–2 张 | 只借款式/配色/材质；第一张为主搭配 | 有则覆盖参考照衣服 |
| 生活场景参考图 | 0–2 张 | 锁定环境、构图、光线氛围；第一张为主构图 | 有则覆盖场景预设 |
| 场景预设 | 0/1 | street/cafe/travel/indoor/selfie，仅无场景图时兜底 | 最低 |
| 补充想法（brief） | 0–1 | 用户额外要求，不改变身份优先级 | 附加 |

参数档位（用户未指定时用默认）：
- 照片风格：`natural` 自然随拍（默认）/ `korean` 韩系日常
- 照片质感：`extra` 手机原片感·更真实（默认）/ `standard` 自然质感·更精致
- 输出尺寸：默认 `1248x1664`（高清半价·竖图）；可选 `2K`、`1K`、自定义像素

### Step 2 · 组装提示词

读取 `references/prompt-template.md`，按模板顺序拼接：**身份块 → 穿搭块 → 场景块 → 场景设定 → 质感块 → 皮肤块 → 光线块 → 负面清单 → brief**。

关键规则（项目实战沉淀，不要自创）：
- 身份参考锁定的是**身份和固有肤色**，不是原照的亮度/白平衡/布光/站姿；必须让模型"根据目标环境重新表现整个人物的受光"，否则输出像抠图贴图。
- 单张人物图时，以该图可见角度为主，**不凭空捏造大幅侧脸**；眼睛可以不看镜头。
- 没有穿搭图 → 模型沿用参考照里的衣服和配饰（精致参考照会带来精致造型，这是"奇怪感"的主要来源，见 Step 4）。
- 韩系（korean）只影响审美氛围，**不添加美白磨皮、强制日光或补闪**。

### Step 3 · 生成

用 `image_gen` 工具（参考图 URL 全部传入，`model_version=seedream_5.0_pro`）：

- prompt = Step 2 组装的完整提示词
- 参考图顺序：人物图 + 穿搭图 + 场景图（全部传入，顺序与 prompt 中编号一致）
- 尺寸/比例：按输出尺寸选宽高比（见 references/prompt-template.md 的尺寸表）；默认 1248x1664 对应 3:4 竖图（width 1248, height 1664，或按工具限制用 3:4）

服务器直连方舟 API（用户自己的服务端场景）见 `references/ark-direct.md`。

### Step 4 · 真实感自检与交付

生成后必须主动检查，不要直接说"可以用了"：

1. **场景 vs 人物割裂检查**：环境（招牌/路人/杂物/光线）是否自然，人物是否有"精致摆拍感"（蝴蝶结/珍珠/饰品/握包站立/低垂眉眼）。割裂 = 参考照自带精致造型 → 建议用户换素人穿搭图（日常服装、无配饰）。
2. **脸 AI 检查**：把生成图与参考照并排放大，对比脸型/发际线/皮肤纹理。不一致 = 模型在往模板脸画 → 建议用户换"素人原相机参考照"（无美颜、自然光、可见皮肤纹理；全身+脸部特写各一张）。若素人照仍救不回 → 说明模型美学先验已到底，提示换本地写实模型+LoRA 路线（重投入）。
3. 交付时标注使用的档位与尺寸，便于用户核对计费。

## 常见问题与对策

| 现象 | 根因 | 对策 |
|---|---|---|
| 场景真了但"脸一眼 AI" | seedream 美学先验，只往好看画 | 换素人原相机参考照；提示词对脸无空间 |
| 造型精致/摆拍感（饰品、精致套装） | 参考照自带造型，模型忠实继承 | 上传素人穿搭参考图（实测有效，优先于参考照衣服） |
| 背景像抠图/贴图 | 未写"按目标环境重新受光" | 身份块必须保留受光重写指令 |
| 背景太干净/没杂物 | 场景块缺少环境杂物指令 | 场景块写"保留真实环境无用细节至少两处" |
| 背景路人/招牌过多抢戏 | 场景参考图本身信息过多 | 减少场景参考图数量，或补 brief 指定 |
